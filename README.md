# Simple Shop

**Simple Shop** — это минималистичный, но функциональный интернет-магазин, полностью построенный на **Jekyll** и стилизованный с помощью **Tailwind CSS**. Проект демонстрирует современные практики веб-разработки, включая SEO-оптимизацию, адаптивный дизайн и улучшенное взаимодействие с пользователем.

## 🚀 Ключевые возможности

- **GitHub Pages Ready**: Сайт изначально спроектирован для полностью бесплатного хостинга на GitHub Pages без необходимости настраивать сторонние серверы.
- **Полностью на Jekyll**: Статический генератор сайтов, идеально подходящий для блогов и небольших магазинов.
- **Tailwind CSS**: Быстрая разработка с использованием утилитарного CSS-фреймворка.
- **SEO-оптимизация**: Автоматическое создание мета-тегов, Open Graph и Twitter Cards для каждой страницы.
- **Адаптивный дизайн**: Бесшовная работа на любых устройствах — от мобильных телефонов до десктопов.
- **Улучшенное UX**: Плавные анимации, визуальная обратная связь при добавлении в корзину и умное управление состоянием корзины.
- **Минималистичный интерфейс**: Чистый и интуитивно понятный дизайн, ориентированный на продукт.
- **Генератор данных (Админка)**: Встроенная страница `admin.html` для автоматической генерации тестового CSV файла с товарами.

## 🛠️ Установка и запуск

### 1. Бесплатный хостинг на GitHub Pages (Основной способ)
Сайт идеально подходит для работы "из коробки" на GitHub Pages.
1. Сделайте форк этого репозитория или загрузите файлы в свой репозиторий на GitHub.
2. В настройках репозитория перейдите в раздел **Settings** -> **Pages**.
3. В разделе Build and deployment выберите Source: **Deploy from a branch**.
4. Выберите ветку `main` (или `master`) и папку `/(root)`.
5. Сохраните изменения. Через 1-2 минуты ваш магазин будет доступен по ссылке вида `https://<ваш_ник>.github.io/<название_репозитория>/`!

### 2. Локальная разработка (Второстепенно)

Если вы хотите вносить изменения в код или тестировать проект локально:

#### Предварительные требования
- **Ruby** (версия 3.3.6 или выше)
- **Bundler**

#### Запуск
1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd simple-shop
   ```

2. Установите зависимости:
   ```bash
   bundle install
   ```

3. Запустите локальный сервер:
   ```bash
   bundle exec jekyll serve
   ```

4. Откройте сайт в браузере по адресу `http://localhost:4000`.

## 📂 Структура проекта

- `_layouts/`: Шаблоны страниц (default, product, home).
- `_includes/`: Переиспользуемые компоненты (header, footer, cart-badge).
- `assets/css/`: Стили Tailwind CSS.
- `assets/js/`: JavaScript-логика.
- `_config.yml`: Конфигурация Jekyll.
- `_data/products.csv`: Каталог товаров.

## 🎨 Дизайн и стили

Сайт использует **Tailwind CSS** для быстрого и гибкого стилизования. Цветовая палитра включает:
- **Синий** (`blue-600`) — основные кнопки и акценты.
- **Зеленый** (`green-600`) — состояния успеха и подтверждения.
- **Серый** (`gray-100`, `gray-800`) — фон и типографика.

## 📱 Адаптивность

Дизайн адаптируется под разные размеры экранов:
- **Mobile**: Компактное расположение элементов, вертикальная прокрутка.
- **Tablet**: Увеличенные отступы, двухколоночный вид для каталога.
- **Desktop**: Полноэкранный режим, улучшенная навигация.

## 🎯 SEO и мета-теги

Каждая страница автоматически генерирует:
- `title` — заголовок страницы.
- `description` — мета-описание для поисковых систем.
- **Open Graph tags** — для корректного отображения в социальных сетях.
- **Twitter Cards** — для интеграции с Twitter.

## 🛒 Управление корзиной

- Товары добавляются в корзину с визуальным подтверждением.
- Состояние корзины отображается в реальном времени.
- При удалении всех товаров из корзины отображается соответствующее сообщение.
