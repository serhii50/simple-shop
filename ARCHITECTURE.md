# Архитектура проекта Simple Shop

## Обзор
Simple Shop — это статический интернет-магазин, полностью построенный на генераторе статических сайтов (SSG) **Jekyll**. В качестве инструмента для стилизации используется утилитарный фреймворк **Tailwind CSS**.

Проект не имеет традиционного бэкенда (сервера или базы данных). Все данные хранятся статично и собираются на этапе компиляции, а динамика интерфейса (например, корзина) реализована исключительно с помощью Vanilla JavaScript и браузерного API.

## 1. Стек технологий
- **Core Engine:** Jekyll (Ruby)
- **Data Source:** CSV-файл (`_data/products.csv`)
- **Templating:** Liquid
- **Styling:** Tailwind CSS (Vanilla CSS для кастомных утилит)
- **Client-Side Logic:** Vanilla JavaScript (ES6)
- **State Management:** `localStorage` (браузер)

## 2. Поток данных (Data Flow)
1. Данные о товарах (название, цена, изображение, описание) хранятся в файле `_data/products.csv`.
2. При сборке (команда `jekyll build` или `serve`) Jekyll использует Liquid-шаблоны из папки `_layouts` и компоненты из `_includes`, подставляя в них данные из CSV.
3. На выходе генерируется папка `_site` с чистыми HTML-файлами.

## 3. Управление состоянием (Корзина)
Корзина покупок работает **целиком на стороне клиента (Client-Side)**.
- Добавление товара: JS-скрипт считывает параметры товара с кнопки "Добавить" и сохраняет JSON-объект в `window.localStorage`.
- Отображение: JS-скрипт на странице `cart.html` считывает данные из `localStorage` и генерирует DOM-элементы с товарами, пересчитывая итоговую сумму.

> Важное архитектурное ограничение: Не предлагать и не использовать серверные решения (Node.js, PHP, базы данных) для работы корзины или обработки заказов. 

## 4. Структура директорий
- `_data/` — источник истины для контента (CSV). Рассматривать как базу данных.
- `_layouts/` — основные макеты страниц (базовый, товар, главная).
- `_includes/` — переиспользуемые фрагменты UI (модули).
- `assets/`
  - `css/` — входной файл Tailwind и кастомные стили.
  - `js/` — скрипты логики (корзина, UI взаимодействия).
