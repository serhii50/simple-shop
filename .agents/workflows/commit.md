---
description: Автоматическое создание коммита
---

// turbo-all
1. Выполни команду `git status`, чтобы посмотреть измененные файлы.
2. Если нет изменений для коммита, сообщи об этом и остановись.
3. Выполни команду `git diff`, чтобы оценить изменения (чтобы составить осмысленное описание коммита).
4. Придумай краткое и емкое сообщение для коммита (commit message) на основе изменений. Желательно следовать Conventional Commits (feat, fix, chore и т.д.).
5. Добавь все измененные файлы в индекс с помощью команды `git add .`
6. Выполни коммит с придуманным сообщением с помощью `git commit -m "<сообщение>"`
7. Сообщи пользователю об успешном коммите, показав сообщение коммита.
