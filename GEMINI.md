# AI ASSISTANT RULES (Gemini / Cursor / Copilot)

Этот файл содержит фундаментальные правила для ИИ-ассистентов, работающих с этой кодовой базой. Обязательно к исполнению.

## Архитектурные Ограничения (Строго!)
1. **ТОЛЬКО СТАТИКА:** Это статический сайт на Jekyll. НИКОГДА не предлагай использовать базы данных (MySQL, PostgreSQL), ORM, серверный бэкенд на Node.js, Python, Ruby on Rails или PHP.
2. **ИСТОЧНИК ДАННЫХ:** Данные лежат локально. Если нужно добавить товары, предлагай редактирование файла `_data/products.csv`.
3. **КОРЗИНА:** Корзина работает только в браузере (Vanilla JS + LocalStorage). Не предлагай серверные сессии или куки.
4. **СТИЛИЗАЦИЯ:** Использовать только утилитарные классы Tailwind CSS. 
    - Избегать написания сырого CSS в `<style>` или `style=""`. 
    - Новый CSS-код в файлы добавляется только в случае крайней необходимости и только через директивы `@apply`.
5. **JAVASCRIPT:** Только Vanilla JS. НИКОГДА не предлагай React, Vue, jQuery или Alpine.js.
6. **ШАБЛОНИЗАТОР:** Используется ИСКЛЮЧИТЕЛЬНО `Liquid`. Строго запрещено предлагать `ERB`, `Pug`, `EJS`. Для работы с коллекциями товаров всегда используй синтаксис Liquid (например, `{% for item in site.data.products %}`).
7. **ТЕМЫ:** При смене темы в `_config.yml` и `Gemfile`, строку со старой темой НЕ удалять, а только комментировать, чтобы всегда видеть список доступных тем.

## Стиль кода и форматирование
1. Код должен быть минималистичным и чистым.
2. При генерации HTML/Liquid соблюдать отступы (2 пробела).
3. Избегать избыточных комментариев в коде, если логика очевидна. Писать комментарии на русском языке.
4. Всегда проверять мобильную адаптивность (классы `sm:`, `md:`, `lg:`) при генерации UI.

## Стиль общения (Tone of Voice)
1. Отвечай кратко и только по делу. Без длинных извинений и введений.
2. Сразу показывай код, если он решает проблему.
3. Если ты не уверен, как работает часть кода (где лежит переменная из Liquid), спроси меня и попроси показать файл, не пытайся угадать расположение папок (не галлюцинируй).
4. Запрашивай актуальное состояние проекта из файла `STATE.md`.
5. Основной язык общения: Русский.
